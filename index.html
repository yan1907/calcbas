SOBRE LAS BASES NUMÉRICAS

- Base 10: Sistema decimal que usamos normalmente (0-9).

- Base 2 (Binario): Solo usa 0 y 1.

- Base 8 (Octal): Usa dígitos del 0 al 7.

- Base 16 (Hexadecimal): Usa dígitos del 0 al 9 y letras A-F.

- Otras bases usan dígitos del 0 a N-1, donde N es la base.
